# 🛒 shop_price_list

**shop_price_list** — это проект интернет-магазина, созданный по индивидуальному заказу. Его ключевая особенность — отсутствие отдельных страниц «Подробнее» для товаров, что упрощает процесс покупки.

---

## 🚀 Основной функционал

- 🔐 **Система регистрации и авторизации** пользователей.
- 🛒 **Корзина и управление заказами**: полноценный функционал для покупок.
- 📈 **Система оптовых и VIP-цен**: возможность установки разных цен для разных групп пользователей.
- 📰 **Мини-блог**: раздел для публикации новостей и статей.
- ⚙️ **Динамическое управление**: меню и блок «Контакты» легко настраиваются.
- 🔍 **Фильтрация и сортировка**: удобные инструменты для поиска товаров по цене и другим параметрам.

---

## 🛠 Используемые технологии

- 🌐 **Django**: основной фреймворк для бэкенда.
- 🎨 **Bootstrap 5**: для создания адаптивного интерфейса.
- 📝 **django-crispy-forms**: для улучшения отображения форм.
- 🗂️ **django-mptt** и **django-mptt-admin**: для реализации древовидных структур (например, в меню).

## ⚙️ Установка и запуск проекта

1.  Клонируйте репозиторий:
    ```
    git clone  https://github.com/zero2312/shop_price_list
    cd shop_price_list
    ```

2.  Создайте и активируйте виртуальное окружение:
    ```
    python -m venv venv
    source venv/bin/activate  # Для Linux/Mac
    venv\Scripts\activate    # Для Windows
    ```

3.  Установите зависимости:
    ```
    pip install -r requirements.txt
    ```

4.  Примените миграции базы данных:
    ```
    python manage.py makemigrations
    python manage.py migrate
    ```

5.  Создайте суперпользователя для доступа к административной панели:
    ```
    python manage.py createsuperuser
    ```
6.  Запустите сервер для разработки:
    ```
    python manage.py runserver
    ```

## 📂 Структура проекта

-   `core/` — содержит основные настройки проекта Django.
-   `media/` — папка для загружаемых медиафайлов.
-   `news/` — приложение, отвечающее за функционал новостей/блога.
-   `shop/` — ключевое приложение, реализующее логику магазина.
-   `users/` — приложение для управления пользователями, их регистрацией и авторизацией.
-   `manage.py` — стандартная утилита Django для управления проектом.
-   `requirements.txt` — файл со списком всех зависимостей проекта.

## ❤️ Особенности реализации

**Система VIP-цен**: Чтобы активировать специальные цены для определённых клиентов, необходимо в административной панели создать группу пользователей с названием `VIP`. После этого при добавлении или редактировании товара можно будет указать отдельную стоимость для этой группы.
